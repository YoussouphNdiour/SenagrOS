Creer un compte

Deux types de comptes sont disponibles :

  • Proprietaire de ferme : Vous creez votre exploitation. Vous choisissez le nom de votre ferme et devenez administrateur.
  • Travailleur : Vous rejoignez une ferme existante avec un code d'invitation fourni par le proprietaire.
Page d'inscription — Choix du type de compte (Proprietaire ou Travailleur)
  1. Choisissez votre type de compte : Je cree ma ferme ou J'ai un code d'invitation
  2. Remplissez vos informations personnelles (nom, email, mot de passe)
  3. Pour un proprietaire : saisissez le nom et la description de votre ferme
  4. Pour un travailleur : collez le code d'invitation recu
  5. Cliquez sur Creer mon compte
Conseil Le proprietaire peut ensuite inviter des travailleurs depuis les parametres de la ferme en generant des codes d'invitation.

Assets — Parcelles

Gerez vos parcelles, terres et unites de production

La page Assets liste tous vos actifs agricoles. Utilisez les filtres et le bouton Nouveau pour ajouter une parcelle.

Vue globale des assets — Tableau avec filtres par type

Creer une parcelle

  1. Cliquez sur Nouveau puis selectionnez le type Parcelle
  2. Saisissez le nom (ex: "Parcelle Arachide Nord"), la superficie en hectares
  3. Selectionnez le type de sol (Argileux, Sableux, Limoneux, Argilo-sableux, etc.) et le type d'irrigation (Goutte a goutte, Aspersion, Pivot, etc.)
  4. Renseignez le code parcelle et l'ilot
  5. Ajoutez une description et des notes si necessaire
  6. Cliquez sur Creer l'asset
Liste des parcelles avec la Parcelle Arachide Nord (3.5 ha)

Reseau d'irrigation

Chaque parcelle peut etre enrichie avec les details de son reseau d'irrigation :

  • Source d'eau : Forage, Fleuve, Lac/Mare, Bassin de retention, Pluie
  • Type de reseau : Goutte a goutte, Aspersion, Micro-aspersion, Pivot, Californien, Gravitaire, Submersion
  • Caracteristiques : Diametre tuyau (mm), Espacement goutteurs (cm), Debit (m3/h)
  • Pompe : Type de pompe, Puissance (CV)
  • Filtration : Disque, Sable, Tamis ou Aucun
  • Etat : Bon, Moyen, Degrade, Hors service
  • Fertigation equipee : Oui/Non
  • Date d'installation
Formulaire Parcelle — Donnees parcelle et reseau d'irrigation (source, type reseau, filtration, etat)

Speculations en cours

Sur la page de detail d'une parcelle, la section Speculations en cours liste automatiquement toutes les cultures actives liees a cette parcelle. Pour chaque culture, vous voyez :

  • Le nom de la culture
  • Le type de culture (arachide, oignon, mil, etc.)
  • La variete
  • La date de semis

Cliquez sur une culture pour acceder a sa fiche detaillee. La liste des parcelles affiche egalement un compteur de cultures dans la colonne Cultures.

Page de detail d'une parcelle — Section "Speculations en cours" avec les cultures liees
Conseil Renseignez le reseau d'irrigation de vos parcelles pour un suivi precis de la consommation d'eau et la planification de la maintenance du reseau.

Animaux

Gestion du cheptel et de l'elevage — Fiches individuelles

Suivez votre cheptel avec des fiches individuelles detaillees : bovins, ovins, caprins, volailles, etc. La liste des animaux affiche des colonnes specifiques : ID individuel, Race, Poids, Type d'elevage et Statut sanitaire avec alertes vaccination.

Liste des animaux — Colonnes ID individuel, Race, Poids, Type elevage, Sante

Ajouter un animal

Le formulaire de creation d'un animal comprend une fiche structuree avec tous les champs necessaires :

  1. Cliquez sur Nouveau et selectionnez le type Animal
  2. Renseignez le nom de l'animal
  3. Dans la section Fiche animal, remplissez :
    • ID individuel (boucle/tatouage) — ex: SN-B-0042
    • Espece : Bovin, Ovin, Caprin, etc.
    • Race : Ndama, Gobra, etc.
    • Robe / Couleur
    • Sexe : Male ou Femelle
    • Date de naissance
    • Type d'elevage : Embouche, Naisseur, Laitier, Mixte
    • Poids actuel (kg)
    • Statut sanitaire : Bon, Surveille, Malade, En traitement
  4. Section Vaccination : derniere vaccination (date + type) et prochaine vaccination planifiee
  5. Ajoutez des particularites (signes distinctifs, comportement)
  6. Cliquez sur Creer l'asset
Formulaire Animal — Fiche structuree avec ID, espece, race, sexe, poids, vaccination

Fiche individuelle

La page de detail d'un animal affiche une fiche individuelle complete avec 4 sections :

  • Identification : ID individuel, nom, espece, race, robe, sexe, date de naissance avec age calcule automatiquement (ex: "2 ans 6 mois")
  • Type d'elevage : categorie (embouche, naisseur, laitier), particularites, notes
  • Suivi ponderal : poids actuel, nombre de pesees, GMQ (Gain Moyen Quotidien en g/jour) calcule automatiquement, et un graphique d'evolution du poids (courbe Recharts) visible a partir de 2 pesees
  • Sante & Vaccination : statut sanitaire avec badge couleur, derniere et prochaine vaccination avec alertes automatiques (en retard ou imminente sous 7 jours), lien vers les journaux medicaux

Peser un animal

Utilisez le bouton Peser en haut de la fiche pour enregistrer une pesee rapide :

  1. Cliquez sur Peser
  2. Saisissez la date et le poids en kg
  3. Cliquez sur Enregistrer

Le poids actuel, le compteur de pesees et le GMQ sont mis a jour automatiquement. Le graphique d'evolution s'affiche des la 2eme pesee.

Fiche individuelle — Identification, suivi ponderal avec GMQ, sante & vaccination avec alertes
Modal Peser — Saisie rapide de la date et du poids pour mettre a jour le suivi ponderal
Conseil Pesez vos animaux regulierement (toutes les 2 semaines) pour un suivi precis du GMQ. Les alertes de vaccination vous previennent 7 jours avant la date prevue.

Ajouter un phytosanitaire

  1. Cliquez sur + Nouveau
  2. Selectionnez la categorie Phytosanitaire
  3. Choisissez la sous-categorie (ex: Herbicide)
  4. Remplissez : nom, nom commercial, matiere active, dose recommandee
  5. Indiquez le DAR (Delai Avant Recolte) et le DDR (Delai De Reentree dans la parcelle) en jours
  6. Selectionnez la classe de toxicite (I a IV) et la forme (Liquide, Granule, Poudre, Suspension)

  8. Indiquez le nombre maximum d'applications par cycle
  9. Listez les organismes cibles (pucerons, mildiou, rouille...) et les cultures homologuees (tomate, oignon, riz...)
  10. Renseignez le stock initial, l'unite, le prix et le seuil d'alerte
  11. Validez avec Creer l'intrant

Journal d'activites

Historique complet de toutes les interventions sur l'exploitation

Le journal centralise tous les logs : activites, semis, irrigation, recoltes, observations, soins, etc.

Journal — 4 logs enregistres (Semis, Observation, Irrigation, Recolte)

Chaque log peut etre filtre par :

  • Type : Activite, Semis, Irrigation, Recolte, Observation, Application intrant, etc.
  • Statut : En attente, Termine, Annule
  • Periode : Date debut / fin

Types de logs disponibles

TypeUsageChamps specifiques
ActiviteTravaux generauxDuree, description
SemisMise en terreMethode, profondeur, ecartements, densite
IrrigationArrosageMethode, duree (min), volume (L)
RecolteCollecteQuantite, qualite, parcelle

Creer un log d'activite

  1. Allez dans Journal > Nouveau
  2. Le type Activite est selectionne par defaut
  3. Remplissez le nom, la date, le statut et les notes
  4. Dans Details activite : duree (heures) et description
  5. Dans Assignation materiel & personnel :
    • Responsable : choisissez la personne en charge de cette tache (recherche par nom)
    • Equipements utilises : selectionnez le materiel necessaire
    • Employes assignes : assignez les travailleurs a la tache
  6. Cliquez sur Creer le log

Le nom du Responsable s'affiche dans la page de detail du log et peut etre modifie via la page d'edition.

Application d'intrant

Enregistrer les traitements phytosanitaires et fertilisations avec melange de produits et conditions meteo

Le formulaire d'application intrant a ete enrichi pour capturer tous les details d'un traitement phytosanitaire professionnel.

Creer un log d'application intrant

  1. Allez dans Journal > Nouveau et selectionnez Application intrant
  2. Dans la section Details application :
    • Choisissez le type d'intrant et la sous-categorie
    • Selectionnez les parcelles a traiter (multi-selection)
    • Indiquez la surface traitee (ha), la methode d'application et la partie cible (feuilles, sol, racines, fruits, tiges, plante entiere)
  3. Dans la section Produits :
    • Ajoutez un ou plusieurs produits au melange (bouillie)
    • Pour chaque produit : recherchez-le par nom, indiquez la dose/ha, l'unite et la quantite totale
    • Cliquez sur + Ajouter un produit pour les melanges multi-produits
  4. Dans la section Volume de bouillie :
    • Indiquez le volume d'eau (L)
    • Renseignez le volume de bouillie par hectare (L/ha)
    • Le volume total se calcule automatiquement (volume/ha x surface traitee)
  5. Dans la section Conditions meteo :
    • Temperature (C), Vitesse du vent (km/h), Humidite (%)
    • Pluie dans les dernieres 24h et prevision de pluie
    • Des alertes automatiques s'affichent si les conditions ne sont pas favorables
  6. Cliquez sur Creer le log
Formulaire Application intrant enrichi — Multi-parcelles, multi-produits, volume bouillie, conditions meteo

Alertes automatiques

ConditionSeuilAlerte
Vent> 19 km/hVent trop fort — risque de derive du produit
Humidite< 40%Humidite basse — risque d'evaporation rapide
Pluie prevueCocheeRisque de lessivage du produit par la pluie
Securite phytosanitaire Le formulaire vous aide a respecter les bonnes pratiques : verifiez les conditions meteo avant traitement, respectez le DAR (Delai Avant Recolte) et le DDR (Delai De Reentree) de chaque produit utilise. Portez toujours les EPI (Equipements de Protection Individuelle).
Melange de produits Vous pouvez combiner plusieurs produits phytosanitaires dans le meme traitement (ex: insecticide + fongicide). Le formulaire calcule automatiquement le volume total de bouillie a preparer.

Suivi des arrosages et de la consommation d'eau

Enregistrer une irrigation

  1. Allez dans Journal > Nouveau et selectionnez Irrigation
  2. Selectionnez la methode d'irrigation dans la liste deroulante :
    • Goutte-a-goutte
    • Aspersion
    • Gravitaire (submersion)
    • Micro-aspersion
    • Pivot central
    • Systeme californien
    • Manuel (arrosoir/seau)

  3. Indiquez la duree en minutes et le volume en litres
  4. Selectionnez la source d'eau (forage, puits, riviere, bassin, citerne, reseau)
  5. Optionnel : renseignez le debit de pompe (L/min)
  6. Cliquez sur Creer le log

Liste des observations — 1 fiche densite de levee (99.17% levee)

Fiche Densite de levee

Cette fiche permet de compter les plants sur des repetitions (10 par defaut) et calcule automatiquement la densite reelle et le taux de levee.

  1. Cliquez sur + Densite
  2. Selectionnez la parcelle, la culture et la variete
  3. Indiquez la densite theorique de semis et la surface d'echantillon
  4. Comptez les plants sur chaque repetition (10 zones de 1 m2)
  5. Les resultats se calculent automatiquement en temps reel
  6. Ajoutez vos remarques (observateur et chef de ferme)
  7. Cliquez sur Enregistrer la fiche
Fiche Densite de levee — 10 repetitions, calcul automatique densite reelle et taux de levee
Exemple 10 comptages (12, 11, 13, 10, 12, 14, 11, 13, 12, 11) = 119 plants total = 119 000 plts/ha = 99.17% de taux de levee sur une densite theorique de 120 000 plts/ha.

Fiche Maladies-Ravageurs

Grille d'observation complete avec 20 ravageurs et maladies pre-definis, 10 blocs d'echantillonnage, calcul automatique du pourcentage d'infestation et alerte quand le seuil de traitement est depasse.

  1. Cliquez sur + Ravageurs
  2. Selectionnez la parcelle, la culture et la variete
  3. Definissez le seuil de traitement (5% par defaut)
  4. Pour chaque bloc (B1 a B10), comptez les plants atteints par ravageur/maladie
  5. Le % infeste et l'alerte se calculent automatiquement
  6. Ajoutez vos preconisations de traitement
Fiche Maladies-Ravageurs — Parcelle, culture, seuil de traitement et grille d'observation par bloc

Calendrier

Vue calendaire de toutes les activites et interventions

Le calendrier affiche vos logs et taches planifiees dans une vue mensuelle interactive.

Calendrier agricole — Vue mensuelle des activites

Creer un modele de calendrier cultural

Un modele definit les etapes du cycle d'une culture (semis, levee, tallage, floraison, maturite...) avec leur duree.

  1. Cliquez sur Templates puis + Nouveau modele
  2. Selectionnez le type de culture — les etapes se pre-remplissent automatiquement
  3. Ajustez les durees de chaque stade selon votre variete
  4. Ajoutez les actions a realiser a chaque stade (semis, desherbage, recolte...)
  5. Cliquez sur Enregistrer le modele
Templates de calendrier — Liste des modeles de cycle cultural
Formulaire creation modele — Nom, type de culture, stades et durees

Assigner un calendrier a une parcelle

Une fois un modele cree, assignez-le a une parcelle avec une date de semis pour generer automatiquement les dates prevues de chaque stade.

  1. Cliquez sur + Assigner un calendrier
  2. Selectionnez la parcelle et le modele
  3. Indiquez la date de semis — les dates prevues se calculent automatiquement
  4. Verifiez l'apercu des dates puis cliquez sur Assigner

Itineraire technique

Chaque plan dispose d'une section Itineraire technique qui permet de planifier les operations culturales etape par etape :

  1. Ouvrez un plan existant
  2. Dans la section Itineraire technique, cliquez sur Ajouter une etape
  3. Remplissez le formulaire :
    • Nom de l'etape : ex: "Semis arachide 55-437"
    • Type d'operation : Preparation du sol, Semis, Desherbage, Fertilisation, Traitement phytosanitaire, Irrigation, Recolte, Autre
    • Jour offset (J+) : nombre de jours apres le debut du plan (ex: J+0 pour la preparation, J+15 pour le semis)
    • Duree : nombre de jours estimes pour l'operation
    • Description et Notes
  4. Cliquez sur Ajouter

Les etapes s'affichent sous forme de timeline numerotee avec des badges de type et de statut. Chaque etape peut etre :

  • Planifie → cliquez Demarrer pour passer a "En cours"
  • En cours → cliquez Terminer pour marquer comme "Termine"
  • Supprimee via le bouton corbeille
Modal Ajouter une etape — Nom, type d'operation, jour offset (J+), duree et description
Exemple d'itineraire arachide 1. Preparation du sol (J+0, 5j) — Labour croise a la charrue
2. Semis (J+15, 3j) — Semis en ligne, 3 graines par poquet
3. Desherbage (J+30, 4j) — Sarclage mecanique
4. Fertilisation (J+45, 2j) — NPK 6-20-10 a 150 kg/ha
5. Recolte (J+120, 7j) — Arrachage et sechage

Lire l'indice NDVI

Le NDVI (Normalized Difference Vegetation Index) mesure la densite et la sante du couvert vegetal a partir d'images satellites :

Valeur NDVICouleurInterpretation
0,0 — 0,2■ RougeSol nu / Stress vegetal severe
0,2 — 0,4■ OrangeVegetation clairsemee
0,4 — 0,6■ JauneVegetation moderee
0,6 — 1,0■ VertVegetation dense et saine

Panneau NDVI par parcelle

Cliquez sur une parcelle pour ouvrir le panneau lateral NDVI :

  • Score NDVI actuel : cercle colore avec la valeur et le label (ex: "Vegetation moderee")
  • Graphique d'evolution : courbe NDVI sur 3, 6, 12 ou 24 mois
  • Selector de periode : boutons 3M / 6M / 12M / 24M en haut du panneau

Donnees satellite reelles Pour obtenir les donnees Sentinel-2 reelles, la parcelle doit avoir une geometrie PostGIS renseignee (polygone GPS). Configurez la variable d'environnement SENTINEL_HUB_CLIENT_SECRET pour activer l'integration Copernicus.
